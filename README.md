# flyUIA — archival recreation

Independent Android recreation inspired by the historic Ukraine International Airlines passenger app.

**Important:** This is not an official UIA app and is not connected to airline systems. Bookings, fares, check-in, boarding passes, flight status, timetable and Panorama Club information are demonstration-only. Do not use them for real travel.

## Included
- Classic UIA-inspired blue, white and yellow visual design
- Flight search interface and airport swapping
- Local demo booking and check-in flow
- Sample boarding pass
- Sample flight status and timetable
- Passenger profile saved on device
- Panorama Club preview
- GitHub Actions workflow to build a debug APK

## Get the APK
Open the **Actions** tab, select **Android debug APK**, then download the **flyUIA-debug-apk** artifact from a successful run.

## Build locally
Use JDK 17 and Gradle 8.9, then run `gradle assembleDebug`.

This is an independent archival recreation and is not affiliated with or endorsed by Ukraine International Airlines.
